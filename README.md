# Consola Wialon

Consola de escritorio (Python + Tkinter) para diagnosticar y monitorear en
tiempo real una flota conectada a Wialon Remote API.

## Uso
1. Doble clic en `Iniciar.bat` (crea el entorno virtual e instala dependencias solo)
2. Ingresa tu Host y API Key/Token de Wialon
3. Conectar

## Funciones
- Listado de unidades con todos sus campos
- KPI en tarjetas (movimiento / ralenti / detenida / sin conexion)
- Generador de token con vigencia y permisos configurables
- Log de la trama cruda para validar la conexion
